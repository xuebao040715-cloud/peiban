# 知夏 · 学姐陪学 (study-senpai)

> 一个会**真的监督你学习**的学姐角色 —— 不是每天说"加油哦"的吉祥物。

把她接到你本地的 Ollama / 任何 OpenAI 兼容端点上，她就变成了：
会问你今天要干什么、会在你拖延时把任务切到"5 分钟就能开始"、会在晚上跟你复盘当天进度的那个人。

**在她身上，角色扮演只是外壳，学习监督才是内核。**

---

## 为什么做这个

GitHub 上角色扮演生态很成熟（SillyTavern 3.3 万星、Open-LLM-VTuber 1.3 万星），
但搜遍 `study supervisor` / `AI tutor` / `accountability` 这些关键词，
能用的"学习监督"项目几乎为零 —— 全是 0–2 星的个人练手。

原因也很简单：**这个需求太个人化了**。每个人的学习计划、拖延触发点和能接受的督促方式都不一样，
所以通用产品做不出来。

这个仓库就是把"能用"的那一套整理出来：**人设 + 可执行的监督机制 + 多客户端配置**。

---

## 特性

- 🎯 **监督机制是具体动作，不是形容词** —— 拆任务、查岗、5 分钟启动法、具体夸奖、日终复盘
- 🧠 **为小模型调过** —— 主提示词控制在 1000 字出头，Gemma 3 12B / Qwen3 14B 这类本地模型不容易跑偏
- 🔌 **不绑定客户端** —— Ollama / Cherry Studio / SillyTavern / Open-WebUI / 任意 OpenAI 兼容接口
- 🀄 **中英双语** —— 主提示词和对话示例都有中文、English 两版
- 🛡️ **有底线设定** —— 不鼓励熬夜，遇到严重情绪问题会跳出角色劝你找真人帮助
- 🎭 **可改姓** —— 名字、专业、称呼、学习时段都能改，不写死

## 快速开始

### 方式一：Ollama（最省事）

```bash
git clone https://github.com/<你的用户名>/study-senpai.git
cd study-senpai
./install.sh                      # 默认基于 gemma3:12b 创建模型 zhixia
ollama run zhixia
```

想换底座模型，直接改 `configs/Modelfile` 第一行的 `FROM`。

### 方式二：Cherry Studio

1. 新建**助手**（日常用助手，不要用智能体 —— 智能体底层套着 Claude Code 的壳，人格会被冲淡）
2. 把 `persona/system-prompt.zh.md` 的内容整个粘进「提示词」
3. 模型选你本地的 `gemma3:12b`，温度调到 `0.9`

详见 [`configs/cherry-studio.md`](configs/cherry-studio.md)

### 方式三：SillyTavern

导入 `character-card/character.json`（或自行打包成 PNG 角色卡）。

### 方式四：任何 OpenAI 兼容客户端

```bash
curl http://127.0.0.1:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zhixia",
    "messages": [{"role": "user", "content": "在干嘛"}]
  }'
```

## 核心机制

这是这个角色和普通"AI 女友"最大的区别 —— 她的监督是**可执行的动作**，不是"你要加油"：

| 机制 | 她具体做什么 |
|---|---|
| **开工对齐** | 每次对话开头先问你今天要做什么，帮你拆成今天能做完的 2–3 件事 |
| **主动查岗** | 隔一阵问你在干嘛、学到哪了；你含糊其辞她会追问 |
| **5 分钟启动法** | 你拖延时她先问"卡在哪"，再把事情切到 5 分钟能开始的一步，最后定个小小承诺 |
| **具体夸奖** | 夸行为不夸人："你那三页笔记整理得很清楚"，而不是"你真棒" |
| **日终复盘** | 每天结束问：做到了什么、没做到什么、明天第一件事是什么 |
| **反完美主义** | 允许你做得不好，但要求你明天补上；不羞辱、不说"我就知道你不行" |

完整说明见 [`workflows/supervision.md`](workflows/supervision.md)

## 定制你自己的学姐

改三个地方就能完全变成你自己的版本（改完记得让她记住）：

| 改什么 | 在哪改 | 为什么重要 |
|---|---|---|
| **名字** | 提示词里的「林知夏」 | 名字是人设的锚点 |
| **称呼** | 加一行"她叫你 XXX，你叫她 XXX" | ⭐ 对角色稳定性影响最大，小模型靠这个定人 |
| **专业/目标** | 提示词里的"同专业" | 写具体专业，她问的问题才贴 |

改完可以写进 `workflows/supervision.md` 的「个人配置」区块，或者直接放进 Cherry Studio 的**知识库**。

## 示例对话

> **你**：今天有点不想学
>
> **知夏**：那我先不问你想不想了。你现在卡在哪，是不知道从哪开始，还是开了头觉得难？

> **你**：不知道从哪开始
>
> **知夏**：那就别看整章了。把书翻到第 87 页，只读那一节的标题和第一段，五分钟。读完跟我说一句你看懂了多少，行不行？

---

> **知夏**：今天那三件事，做完了吗？
>
> **你**：前两件做完了，第三件没动
>
> **知夏**：行，那不算亏。第三件是什么卡住的？明天你第一件事就是它，别的先放。

更多见 [`persona/examples.md`](persona/examples.md)

## 一些小提醒

- **12B 及以下的小模型，长提示词会降低人设稳定性。** 如果你用的是 7B/8B，建议只保留 `persona/system-prompt.zh.md` 里的【你是谁】【你怎么管我】【说话的规矩】三节。
- **想让她记得住长期进展**，用客户端自带的记忆 / 知识库功能，别指望模型自己的上下文 —— 窗口一满就忘了。
- **想定时查岗**，Cherry Studio 的智能体支持定时任务，可以配个"每天 21:00 检查今天学得怎么样"。
