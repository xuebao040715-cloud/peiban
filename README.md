# 陪伴

**作者：xuebao040715-cloud** · [GitHub 项目](https://github.com/xuebao040715-cloud/peiban)

转载和发布二次开发版本须保留作者署名及项目链接，详见 [署名说明](NOTICE.md) 与 [许可证](LICENSE)。

一点一滴，一起向前。一个住在本机的 AI 伙伴，默认叫「知夏」——不催你，也不评判你在忙什么。

基于原 `study-senpai` 角色包继续构建，保留原 Git 历史、提示词、角色卡和客户端配置。项目显示名为 **陪伴**，代码标识为 `peiban`。

## 开始使用

需要 Node.js 22 或更新版本，以及已启动的本机 Ollama。

### Windows

双击 **启动陪伴.cmd**，保留打开的服务窗口，然后在浏览器访问：

**http://127.0.0.1:3210**

启动脚本优先使用 PATH 中的 Node.js；如果没有，会尝试这台机器已有的 Codex Node.js 运行时。不安装任何 npm 依赖。

### 命令行

```sh
node app/server.mjs
```

在项目目录运行。服务启动后打开上面的地址。按 Ctrl+C 停止服务。

如果提示无法连接模型，先启动 Ollama：

```sh
ollama serve
ollama pull gemma3:12b
```

如果本机已安装所选模型，无需重复下载。默认选择基础模型 `gemma3:12b`，由应用加载自己的陪伴提示词，避免旧模型内置人设与应用提示词重叠。可在「偏好设置」切换本机模型。

## 这一版能做什么

- **陪你聊聊**：本地 AI 对话、昵称、模型选择、重试和停止生成；提供「聊聊心情」「有点不想学」「安排今天」「今日小复盘」入口。
- **此刻在做什么**：首页一排小标签（写代码 / 工作 / 学习 / 打游戏 / 看剧 / 健身 / 发呆 / 休息），点一下就告诉她你在干嘛，对话会带上这个背景。不说也行，她不会追问。
- **边说边看**：回复边生成边显示，不用等整段说完；偏好设置里可以开朗读、调发散程度、单条回复上限和上下文长度。
- **自定义语音**：朗读引擎可在系统语音和本地 TTS 之间切换，支持 OpenAI 兼容 / GPT-SoVITS / 自定义接口，音色和语速都能调，详见下文。
- **桌宠**：一个置顶小窗口，定时看一眼屏幕、猜你在做什么，用角色的口吻说一句；形象可以换，详见下文。
- **记住跨天的事**：每积累 20 条消息自动整理出一段「回忆」和几条长期事实，下次对话自动带上；也可以在「陪伴记录」里手动整理、逐条删除。
- **今天想做的**：按日期记下想做的事，能打勾、能删；没做完也不会有人催。
- **一起待一会儿**：5 / 25 / 50 分钟，安静陪你待着；结束后记一笔「一起待过的时间」。刷新页面会恢复计时，提前结束不计。
- **留下此刻**：随手写一句当下的想法，不用完整，也不用是成果；可导出 JSON 备份。
- **让聊天有上下文**：提供当天计划、昵称和最近 6 条记录；发送最近 24 条聊天消息。完整聊天保存在本机，但不会全部塞进模型。

没有填充虚构的聊天、任务或学习统计。首页从真实的空白状态开始。

## 自定义角色

打开左侧 **角色工坊**（或聊天标题栏的 ✧），可以设置名字、身份、性格、说话语气、倾听/学习倾向、回复长度、表情习惯、开场白、对话示例和补充偏好。

四个模板：温柔学姐、活力搭子、安静树洞、专注教练。选择模板只修改表单草稿；点击「保存并使用角色」后生效。更改设定会创建新的对话上下文，历史聊天不删除，原角色名字仍会保留。任务和近期记录仍作为共享上下文。

「导出角色包」保存当前表单设定为 `peiban-character` v1 JSON，不附带聊天、任务、记录或昵称。「导入角色包」仅接受此格式（最大 64 KiB），先展示草稿，保存后才启用。原 SillyTavern 角色卡与聊天备份不属于此格式，不能直接导入。用户自己写入性格或示例中的信息会随角色包导出。

角色设定会发送给模型，但实际遵循程度取决于模型。当前应用一次启用一个角色；可用导出文件保存多个版本。生成过程中不能切换角色。

## 自定义头像、背景和颜色

进入左侧 **外观装扮**：

- 上传陪伴角色头像和自己的头像；支持 JPG、PNG、WebP（每张原图不超过 10 MB）。头像自动居中裁切成 256 × 256。
- 设置背景图，拖动「图片浓度」调整显示强度；可移除背景并只用纯色。
- 选择森系绿、雾海蓝、落日玫、柔雾紫、暖杏茶预设，也可分别自选主题色和背景底色。
- 修改即时预览，点击「保存外观」才持久保存。「取消预览」恢复已保存内容；离开外观页也会取消未保存的预览。「恢复默认」先展示默认外观，点击保存后生效。

图片在浏览器内压缩，只存入本机记录，不发送给模型。背景图长边最长 1600 像素。角色包导出只含人设；全量记录备份包含头像和背景。外观设置独立于人设，不会重置聊天上下文。头像用于当前角色；历史其他角色仍显示名字首字。

角色工坊现采用有最大宽度的双栏编辑与预览布局，窄屏自动堆叠；页面资源带版本号，更新后刷新页面即可获取新样式。

## 自定义语音（可选）

默认用浏览器/系统的语音合成（`speechSynthesis`），免费、离线、零依赖。想换成自己的音色，就在偏好设置里把 **朗读引擎** 切成「本地 TTS」，指向你自己跑的服务——音频只在本机之间流动，不经过对话模型，也不上传。

支持三种协议：

| 协议 | 请求 | 适用 |
|---|---|---|
| OpenAI 兼容 | `POST {地址}/v1/audio/speech`，JSON `{model,input,voice,response_format}` | 任何提供 OpenAI 兼容语音接口的服务 |
| GPT-SoVITS | `GET {地址}/tts?text=…&text_lang=zh&ref_audio_path=…` | GPT-SoVITS 自带的 `api.py`（默认 9880 端口） |
| 自定义接口 | `POST {地址}`，JSON `{text,voice}`，直接返回音频 | 自己写的小服务 |

三个配置项：

- **服务地址**：只接受 `127.0.0.1` / `localhost`，服务端会拒绝远端地址，避免这个代理变成任意转发。
- **音色 / 参考音频**：OpenAI 协议填音色名；GPT-SoVITS 填参考音频的绝对路径。
- **模型名**：OpenAI 协议用，默认 `tts-1`。

以 GPT-SoVITS 为例：

```sh
python api.py -a 127.0.0.1 -p 9880
```

然后偏好设置：朗读引擎「本地 TTS」→ 协议「GPT-SoVITS」→ 服务地址 `http://127.0.0.1:9880` → 音色填参考音频绝对路径 → 点「试听这句」。

**失败会自动回退**：连不上、超时或返回错误时，这一句改用系统语音播报，并在页面上提示原因，不会静默卡住。朗读按句切分逐句请求，句间留一点停顿——整段一次性合成听起来像念稿。

## 桌宠（可选）

一个独立的小窗口，会在后台看着你的屏幕，猜你在做什么，然后用角色的口吻说一句。默认关闭。

**打开方式**：偏好设置里勾上「启用桌宠」，然后双击项目里的 `桌宠.cmd`。它会：

1. 如果陪伴服务没起，先在后台把 `app/server.mjs` 拉起来；
2. 用 Edge/Chrome 的 app 模式开一个 300×430 的无地址栏窗口；
3. 按偏好设置里的 `alwaysOnTop` 把窗口置顶、贴到屏幕右下角。

也可以在主应用偏好设置里点「打开桌宠窗口」，开一个普通弹窗。

**它怎么知道你在干什么**：到点（默认每 5 分钟）截一张屏幕图，缩到 1024 宽，作为一张图片发给本机 Ollama 的视觉模型，让模型返回 `{"doing":"在看论文","line":"…"}`。

- 截图只在内存里用一次，不写盘、不上传，用完即弃；
- 默认 15 秒内只能观察一次，避免连续截屏；
- 视觉模型自动挑选（名字里带 vl / vision / llava / minicpm 等），也可以在偏好设置里指定；
- 建议 `ollama pull qwen2.5vl:7b`，7B 在这张卡上大约 10 秒出结果；
- 桌宠说出口的话会走「朗读」设置（系统语音或你接的本地 TTS）。

**换形象**：点桌宠上的「换形象」，选一张图（JPG / PNG / WebP，≤10 MB）。图片会在浏览器里居中裁成方形、压成 webp 后存进外观设置（`appearance.petImage`），和头像一样只留在本机。没上传时用角色头像，再没有就显示角色名字的第一个字。

**它不会做的事**：不能操作你的鼠标键盘、不能读其它程序的内部数据、不在后台常驻（关掉窗口就停）、不会把截图发给任何远端——代理只连本机 `127.0.0.1:11434`。

## 舞台界面与「直说模式」

聊天页是一块深色舞台：左边是对话，右边是角色立绘（会呼吸、会发光），顶部一排状态胶囊。

| 胶囊 | 含义 |
|---|---|
| 模型名 | 当前本机 Ollama 模型，鼠标悬停看上下文长度 |
| local | 所有请求只到 `127.0.0.1:11434`，没有中间层 |
| 直说 开/关 | 直说模式，见下 |
| 延迟 | 从发消息到第一个字出现的耗时，超过 8 秒会变暖色 |

### 直说模式

打开后，系统提示词会追加一条：不写免责声明、不用「作为 AI」这类自我限定、不主动说教或劝告。

**这不是绕过模型的安全机制**，而是让应用不再替模型加一层客套。是否真的不拒答，取决于你选的模型本身：

- 常规对齐模型（如 gemma3、qwen2.5）仍会拒答敏感请求；
- 想要真正没有拒绝层，得自己跑一个去对齐（abliterated）的本地模型，再在偏好设置里选它。

应用只做一件事：把请求原样发给你本机的模型，不加平台的过滤层、不转给第三方。

### 按住说话（可选）

角色卡片上的「按住说话」按钮会录音，交给本机的语音识别服务转成文字，然后自动发出。

需要自己跑一个 ASR 服务，同样只接受本机地址：

| 协议 | 请求 | 适用 |
|---|---|---|
| OpenAI 兼容 | `POST {地址}/v1/audio/transcriptions`（multipart，字段 `file`、`model`） | faster-whisper、whisper.cpp 的 openai 兼容服务 |
| whisper.cpp | `POST {地址}/inference`（multipart，字段 `file`、`response_format=json`） | whisper.cpp 自带的 server |

没配置时会提示「连不上本地 ASR」，打字照常可用。

## 个人微信

目标是像好友一样聊天，但 **当前没有接通个人微信的收发消息功能**。官方微信登录接口用于网站身份登录，不能据此读取和回复个人好友消息。已核实的公众账号消息接口也不等同于个人号聊天接口。

当前仅展示真实的「个人号 · 未接入」状态，没有扫码登录、联系人读取或自动发送功能。详细核实与接入缺口见 [docs/WECHAT.md](docs/WECHAT.md)。

## 数据与边界

- 数据在 `personal/state.json`，已被 `.gitignore` 排除。保存采用临时文件替换，并检查版本，防止多窗口互相覆盖。
- 只监听 `127.0.0.1`，Ollama 地址也限定本机；没有遥测、账号或云同步。数据为本机明文文件，不是加密保险箱。
- 朗读文本会发给你自己填的本地 TTS 服务（必须是本机地址）；不会发给对话模型，也不上传到远端。
- 导出备份：陪伴记录 → 导出备份。恢复时先停止服务，备份现有文件，再把导出的同版本 JSON 复制为 `personal/state.json`，重新启动。
- 专注提醒在页面打开时显示。关闭页面后不会发系统通知，重开后会结算已到期的时段；计时完成不代表验证了实际学习行为。
- 知夏只能读取你输入的对话、计划和记录，不能监控屏幕或自动替你完成任务。
- 回复边生成边显示，长时间没有输出可以随时停止。AI 回复可能有误。朗读使用系统自带语音，不联网。

## 开发与验证

```sh
npm run check
npm test
```

也可以直接执行 `node --test tests/server.test.mjs`。测试使用临时目录和模拟 Ollama，不读取用户记录。

环境变量：`PORT` 更换默认 3210 端口；`PEIBAN_DATA_DIR` 指定数据目录；`OLLAMA_URL` 指定本机 Ollama 地址（默认 `http://127.0.0.1:11434`）。

原角色包的独立客户端用法见 [docs/legacy-role-pack.md](docs/legacy-role-pack.md)。
