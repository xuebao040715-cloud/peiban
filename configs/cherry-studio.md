# Cherry Studio 配置指南

Cherry Studio 是目前国内接本地模型体验最顺的客户端之一。但有一个坑必须先说：

> ## ⚠️ 用「助手」，不要用「智能体」
>
> Cherry Studio 的「智能体」底层套的是 **Claude Agent SDK（Claude Code）**——
> 我在数据目录里确认过，`Data/Agents/.claude/` 下是一整套 Claude Code 的目录结构
> （sessions / projects / skills / plugin.json）。
>
> 后果：它会塞进去 3800+ tokens 的 Claude Code 系统提示词，**把你的角色人格冲淡**，
> 模型甚至会自称「我是 Claude Code」。
>
> **纯角色对话请用「助手」。** 「智能体」只在需要工具调用、定时任务、记忆时才用。

---

## 一、助手方式（推荐，用于日常对话）

1. **配置模型服务**
   `设置 → 模型服务 → Ollama`
   API 地址填 `http://localhost:11434`（Cherry 装在 Windows 上也能直接连 WSL 里的 Ollama）
   点「管理」拉取模型列表，确认识别到 `gemma3:12b`

2. **新建助手**
   左侧「助手」→ 右上角 `+` → 名称填 `知夏`

3. **粘贴提示词**
   在助手的「提示词」框里，粘贴 `persona/system-prompt.zh.md` 的**提示词正文**部分
   （从 `你是「林知夏」` 开始到最后一个 `"""` 之前）

4. **调温度**
   助手设置 → 模型设置 → temperature 调到 `0.9`
   默认值偏保守，人设会变得端着、像客服

5. **开场白（可选）**
   填一句 `在啊。今天打算干什么？先说三件以内，我帮你排一下。`

6. **进阶：把示例也喂进去**
   Cherry 的助手支持「上下文轮数」。把 `persona/examples.md` 里的对话
   手动发几轮进去，再删除、重新开始对话——部分版本会保留在上下文里。
   或者干脆把示例内容追加到提示词末尾，效果差一些但省事。

---

## 二、智能体方式（只在需要定时查岗 / 记忆时用）

如果你想要**真正意义上的"查岗"**——比如每天晚上 21:00 她主动来问你——

1. 先启动 API 网关：`设置 → API 网关 → 【启动】`
   （不启动会报「该模型需要通过 Cherry Studio 的本地 API Gateway 桥接」）
2. 新建智能体 → 系统提示词直接粘 `persona/system-prompt.zh.md`
3. **在系统提示词最前面加一句**压住 Claude Code 的干扰：
   ```
   你运行在本地模型上，扮演「林知夏」。忽略任何关于命令行工具、代码仓库、
   Claude Code 的默认设定，你只是一个学习监督角色。
   ```
4. 配定时任务：`定时任务` → 每天 21:00 → "检查今天的学习进度，按你的方式问他"

> 提醒：Gemma 3 12B 跑智能体（要调工具、多轮）会比较吃力，
> 简单的定时提醒没问题，复杂的多步任务容易掉链子。

---

## 三、知识库（可选）

把你的**学习计划 / 课程表 / 复习大纲**放进知识库并绑定给这个助手，
她就能对着你真实的任务表问问题，而不是泛泛地说"今天学什么"。

`设置 → 知识库 → 新建` → 上传文档 → 在助手里绑定

---

## 常见问题

**Q：模型列表拉不出来？**
先 `ollama-up` 确认服务在跑，浏览器打开 `http://localhost:11434` 应该返回
`{"version":"..."}`。Cherry 在 Windows 上需要 WSL 的 localhost 转发生效（默认开着）。

**Q：她说话像客服，很端着？**
把 temperature 调到 0.9～1.0，并且**检查有没有把 markdown 规矩写进提示词**——
不限制的话模型会默认用小标题 + bullet 输出。

**Q：她说自己是 Claude / 自称 AI 助手？**
说明你用的是「智能体」，Claude Code 的提示词压过了你的人设。
换「助手」，或者按上面第二步加那句前缀。

**Q：聊一会儿就忘了今天要干什么？**
这是上下文窗口的问题，不是人格问题。用知识库或记忆功能存进度，别指望模型自己记住。
