# 个人微信接入 · 当前状态

用户目标：在个人微信里像与好友一样和自定义角色聊天。核实日期：2026-09-19。

## 已核实

- [微信网站应用登录](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html)：OAuth 登录授权提供网站登录与相应用户基本信息能力，不是个人好友消息收发权限。
- [公众账号接收普通消息](https://developers.weixin.qq.com/doc/offiaccount/Message_Management/Receiving_standard_messages.html)：用户给公众账号发消息后，微信把 XML 推送给开发者服务器；此能力不等于个人号好友聊天。
- 本轮没有找到可以直接用于该目标的公开官方个人号聊天 API；这是一项核实结果，不是断言所有未来通道都不存在。
- [微信软件许可及服务协议](https://weixin.qq.com/cgi-bin/readtemplate?lang=zh_CN&t=weixin_agreement&s=default) 8.2.1.4–8.2.1.6 对非授权插件、第三方接入和自动化有约束，8.5 列出账号处理措施。个人号第三方桥接的账号风险需要在选型时考虑。

## 本轮交付边界

应用中的个人微信状态为「未接入」。没有凭据，没有建立会话，没有读取联系人或发送消息。不能将普通扫码登录页面包装成“微信好友机器人”。

## 还缺什么

需要一个可用且获准的个人微信消息通道，及其官方或服务方协议文档、账户权限和本地接入方式。本轮没有为用户购买桥接服务、安装注入工具、修改微信客户端或部署公网入口。

通道确定后，适配层应满足：只接受绑定用户；排除群聊与自身消息循环；消息去重；每位用户独立会话与记录；明确错误和断线状态；验证收发能力后才能标记已连接。不得把其他联系人的消息默认加入当前用户的学习记录。

本机网页服务保持仅监听 127.0.0.1，现有数据接口不能直接暴露给公网。公众号或企业微信是不同产品形态，只有用户选择后才另行实现。
